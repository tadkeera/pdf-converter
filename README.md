# 📄➜📊 PDF Converter — محوّل PDF إلى Excel

تطبيق شامل ومتكامل يحوّل **أي عدد من ملفات PDF** إلى **ملفات Excel منفصلة** — حتى **1000 صفحة للملف الواحد** — مع استخراج **اسم التاجر / الوكيل** تلقائياً وجعله عنوان ملف الـ Excel، وإمكانية **استثناء أي صفحة** برقمها أو بعنوانها.

A complete, professional PDF→Excel converter for **Windows (EXE)** and **Android (APK)**: batch-convert unlimited PDF files (up to 1000 pages each), auto-detect the merchant/agent name and use it as the Excel file title, and skip any page by number or by its title/header text.

## 🖥️ نسخة الوندوز (EXE)

1. حمّل `PDFConverter-Windows-v1.0.0.exe` من صفحة Releases.
2. انقر نقراً مزدوجاً — **لا يحتاج أي تثبيت**؛ الملف يعمل مباشرة (كل المكتبات مدمجة بداخله).
3. (اختياري) لإنشاء برنامج Setup حقيقي مع اختصارات: استخدم `desktop/installer.iss` مع [Inno Setup](https://jrsoftware.org/isinfo.php).

### الاستخدام
1. اضغط **➕ إضافة ملفات** واختر واحداً أو أكثر من ملفات PDF (أو **إضافة مجلد** لاستيراد كل ملفات المجلد).
2. اضبط الخيارات:
   - **الحد الأقصى للصفحات** (الافتراضي: 1000).
   - **استثناء صفحات برقمها**: مثال `1,3,5-9`.
   - **استثناء صفحات بعنوانها**: اكتب كلمات يفصل بينها `,` — أي صفحة يبدأ عنوانها أو تحتوي هذه الكلمات في أول أسطرها تُستثنى.
   - **استخراج اسم التاجر تلقائياً** (مفعّل افتراضياً) أو اكتب **اسماً يدوياً**.
3. اضغط **▶ بدء التحويل** — شريط تقدم + سجل مفصّل.
4. كل ملف PDF يصبح ملف `.xlsx` منفصلاً داخل مجلد **PDF CONVERTER** (في `Documents\PDF CONVERTER` افتراضياً)، واسم الملف هو اسم التاجر/الوكيل المستخرج.

### تشغيل من المصدر (للمطوّرين)
```bat
cd desktop
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### بناء الـ EXE بنفسك
```bat
cd desktop
build_exe.bat
:: الناتج: dist\PDFConverter.exe
```

## 📱 نسخة الأندرويد (APK)

1. فعّل "تثبيت من مصادر خارجية" من إعدادات أندرويد.
2. افتح `PDFConverter-Android-v1.0.0.apk` وثبّته.
3. اضغط **➕ إضافة ملفات** واختر ملفات PDF (من أي تطبيق — الملفات، Drive، الإيميل…).
4. اضبط الخيارات نفسها (الحد الأقصى للصفحات، استثناء الأرقام/الكلمات، الاسم التلقائي/اليدوي).
5. اضغط **▶ بدء التحويل** — تُحفظ كل ملفات Excel تلقائياً داخل مجلد **PDF CONVERTER** في `Download/PDF CONVERTER`، وتظهر في السجل مع زر **مشاركة الملفات** لإرسالها لأي تطبيق.

### بناء الـ APK من المصدر
```bash
cd android
./gradlew :app:assembleRelease   # يتطلب JDK 17 + Android SDK 34
# الناتج: app/build/outputs/apk/release/app-release-unsigned.apk
# ثم وقّعه: zipalign + apksigner
```

## 🧠 كيف يعمل استخراج اسم التاجر/الوكيل؟

1. يفحص التطبيق أول 5 صفحات من كل ملف PDF.
2. يبحث عن حقول معروفة: `اسم التاجر، اسم الوكيل، اسم المورد، المستورد، الشركة…` و `Merchant, Agent, Importer, Supplier, Company…`.
3. يأخذ القيمة التي تلي الحقل (نفس السطر أو السطر التالي) كنص نظيف.
4. إن لم يجد شيئاً، يستخدم عنوان الملف (Metadata) ثم أول سطر ذي معنى من الصفحة الأولى.
5. الاسم الناتج يُستخدم **كعنوان لملف الـ Excel** (اسم الملف) ويظهر أيضاً كشريط عنوان داخل كل ورقة.
6. يمكن دائماً تجاوز النتيجة بكتابة **اسم يدوي**.

## 🚫 كيف يعمل استثناء الصفحات؟

- **بالرقم:** `1,3,5-9` → يستثني الصفحات 1 و3 و5 و6 و7 و8 و9.
- **بالعنوان/الكلمات:** اكتب `شروط, ملخص` → أي صفحة يظهر فيها أيٌّ من هذه الكلمات في عنوانها أو أول 15 سطراً منها تُستثنى.
- الصفحات الفارغة تُستثنى تلقائياً.

## 🛠️ التقنيات

- **المحرك (سطح المكتب):** Python — PyMuPDF (استخراج النصوص + كشف الجداول) + OpenPyXL (كتابة Excel بدعم RTL).
- **الويندوز:** PyInstaller → ملف EXE واحد مكتفٍ ذاتياً.
- **أندرويد:** Kotlin + PDFBox-Android (استخراج النصوص بمواضعها) + كاتب XLSX مخصص خفيف (بدون مكتبات خارجية ثقيلة).
- **CI/CD:** GitHub Actions — بناء الـ EXE على Windows و الـ APK على Linux تلقائياً عند كل push.

## 📝 ملاحظة عن الملفات الممسوحة ضوئياً (OCR)

التطبيق يتعامل بامتياز مع ملفات PDF النصية. لملفات **المسح الضوئي (صور)** يمكن تفعيل OCR: ثبّت [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) على ويندوز مع بيانات اللغة العربية وأضف `pytesseract` للمشروع. التطبيق يتخطى الصفحات المصوّرة بأمان إن لم يتوفر OCR.
